# Purpose

Verify acceptance rules and observable CLI behavior.

## Ownership

Core gate tests, subprocess CLI tests, and `self-host.test.ts`, which checks the complete maintained root and an archived copy through the native CLI. `reference.ts` and `compiler.ts` own the independent development TypeScript oracle and bounded compiler-session regressions; neither ships in the npm package.

`cli.ts` supplies fixed-entry CLI launches and environment defaults. `runCli` returns raw results; an explicit `env` replaces defaults. `project.ts` writes provided fixture sources and policy. `terminal.ts` supplies PTY probing, quoting, and ANSI state. Keep specialized async, copied-checker, and PTY lifecycle handling local.

`report-browser.test.ts` is an opt-in browser technical test, skipped by the ordinary suite unless `BONSAI_BROWSER_QA=1`, and outside the published package. It generates reports through the actual CLI, verifies that HTML creation does not replay handlers, then opens only the report bytes with Chromium `setContent`. Load the isolated pinned Playwright tool through its temporary package context, block HTTP(S) requests, and archive actual screenshots separately from assertion results. Do not claim visual quality without reviewing those captures.

`html-report-timeout.test.ts` dispatches the registered command deadline during actual report delivery, checking first-failure exit status, matching structured diagnostics, and preservation of the prior artifact. Keep its independent named-filesystem-import preload control and positive dispatch marker; a failed setup or a timeout before evaluation does not establish the delivery regression.

`native/` owns development-only comparison and benchmark tools. Keep their real production dependencies traceable; test classification does not grant ancestry to unrelated production. `native-session-owner.ts` is the maintained child entry for owner-death tests, taking the consuming root, JSON file list, and descriptor destination as arguments. Optional `--ready <path>` arguments signal completed warmup and enable graceful SIGTERM cleanup for reuse probes; ordinary owner-death callers retain their existing behavior. Its real collector/session imports stay visible to the source graph rather than embedded in generated script strings.

## Local Contracts

Assert outputs, streams, exit codes, and candidate behavior. Check presentation regressions use real PTYs and inspect ANSI foreground/dim state on meaningful text, including wrapped continuations and independently redirected streams. Use isolated fixtures and remove them in cleanup. CLI tests must exercise the executable rather than duplicate its parser.

## Verification

`bun run test` includes the executable product contracts and gives each test file a fresh module/global scope with Bun's `--isolate`; tests remain sequential. This prevents compiler-oracle and worker lifecycle state from being shared across files. It does not extend any product feedback deadline. `bun run test:features` runs the product contracts alone.
